# V3 变更说明

V3 基于 V2，重点补充“阶段综合项目的 Web 可视化调试台”。

## 主要变化

1. Lab 01~14 仍保持 `Main` / CLI 为主，不给单概念实验批量增加前端。
2. Stage 1 仍为 CLI，专注观察 Minimal Agent Loop。
3. Stage 2 增加简单 Chat Debugger，展示 Conversation / State / Plan / Memory。
4. Stage 3 增加 Long-running Agent Debugger，展示 Context / Compaction / Checkpoint / Resume / Evaluator。
5. Stage 4 增加 Mini Agent Harness Console，展示 Tool / Trace / Approval / Memory / 可选 Worker。
6. 新增 `docs/04_Web可视化调试台规范.md`。
7. 新增 4 份 Stage 专用实现 Prompt：
   - `docs/prompts/stage01_minimal_agent.md`
   - `docs/prompts/stage02_stateful_agent.md`
   - `docs/prompts/stage03_long_running_agent.md`
   - `docs/prompts/stage04_agent_harness.md`
8. Web 技术固定为 JDK `HttpServer` + HTML/CSS/原生 JavaScript，不引入 Spring Boot 或 Node 前端工具链。
9. `AGENTS.md` 增加 Web 教学边界：Web 层必须薄，Agent 核心不得写进 Handler / JavaScript。

## 为什么这样改

随着 Agent 能力组合，很多关键机制只看最终文本答案很难理解。V3 把前端定位成“Agent 调试器”，而不是产品 UI，让学习者在浏览器里看到真实的内部状态变化。
